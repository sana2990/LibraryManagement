# LibraryManagement
Online library

The Online Library Management System is a React-based web application that allows users to browse books, search books, filter books by category, view detailed information about books, and add new books to the library.

This project is built using:

React JS
React Router DOM
Redux Toolkit
CSS

1. Home Page

The home page displays all books in the library. The page has a Project title, popular books section, book cover images, author names to give user an overview of the best books available in teh library.

Users can view highlighted popular books on the homepage.

2. Browse Books Page

The Browse Books page allows users to view books category-wise, browse Fictional Books, browse Sci-Fi Books, browse Thriller Books, browse Motivational Books

Each book card displays:

Book cover image
Book title
Author name

Users can click on a book to view more details.

3. Search Functionality

The project includes a search feature where users can search books by book name or by author name
The search updates the displayed books dynamically.

4. Filter Functionality

Users can filter books according to category.
Available filters:

-> Fictional
-> Thriller
-> Motivational
-> Sci-Fi

5. Book Details Page

When a user clicks a book, a detailed page opens.
This page displays:

Book title
Book image
Author name
Book description

6. Add Book Page

Users can add a new book using a form.

The form contains:

Book title
Author name
Description
Genre
Cover image URL

After submission:

The new book is stored in Redux state
The book appears in the Newly Added Books section
